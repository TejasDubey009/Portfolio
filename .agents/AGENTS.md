# Workspace Rules

## Implementation & Change Planning Rules
- Whenever requested to make changes to the codebase:
  1. Always include a step in the verification plan to test and verify that the change does not break any existing functionality or components.
  2. Create a detailed implementation plan first before making changes, outlining all affected files, steps, potential risks, and verification steps.
  3. Obtain user approval on the plan before executing code edits.
